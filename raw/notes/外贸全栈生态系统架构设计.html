三、模块拆解与实现

模块 1：独立站（WordPress + Astro）

职责：公司资质展示 + 产品目录 + 产品详情 + 联系方式 + 询盘表单

技术方案：

WordPress (docker-wordpress)  →  主站（公司介绍、联系、博客）
  ├── 产品目录页（自定义文章类型：Products）
  ├── 产品详情页（含规格参数、PDF下载）
  ├── 公司资质页（ISO/CE/PVOC 证书展示）
  └── 询盘表单（WPForms → Webhook → n8n → CRM）

AstroWind (astrowind)  →  产品详情静态页（SEO 友好）
  └── 从 Obsidian 产品 Markdown 自动生成

产品数据流：

Obsidian 产品 Markdown
    ↓ (n8n Webhook 触发)
WordPress REST API（创建/更新产品文章）
    ↓
独立站产品页自动更新

关键插件：

  • WP REST API（核心自带）
  • Advanced Custom Fields（产品规格字段）
  • WPForms（询盘表单 → Webhook）
  • Yoast SEO（SEO 优化）

Astro 的角色：用 Astro 生成产品详情的静态 HTML 版本，SEO 极致优化，作为独立站的”产品详情”子目录，或单独域名。WordPress 做动态内容（博客/新闻），Astro 做静态产品页。

模块 2：社媒矩阵（Postiz）

职责：Facebook 多账号排期发布 + 数据回收

已有基础：Postiz docker-compose 已配好 Facebook App ID/Secret、LinkedIn、Temporal 调度

矩阵架构：

Postiz (:4007)
  ├── 账号 1：公司主页（品牌窗口）
  ├── 账号 2：老板个人号（行业专家）
  ├── 账号 3：业务员号 A（产品顾问）
  ├── 账号 4：业务员号 B（产品顾问）
  └── 定时发布队列（Temporal 调度）

内容自动排期流：

Obsidian 内容库（Markdown 帖文模板）
    ↓ (n8n 定时读取)
DeepSeek AI（生成/润色英文帖文）
    ↓
Postiz API（排期发布到各账号）
    ↓
发布数据回收（曝光/互动/点击）
    ↓
n8n → CRM（线索归因）

Postiz 已支持的平台：Facebook、LinkedIn、X/Twitter、Instagram、TikTok、YouTube、Pinterest、Threads、Reddit、Discord

模块 3：WhatsApp 聊单系统

职责：客户沟通 + 聊天记录同步到 CRM

方案选型：

方案优点缺点
WhatsApp Business API（官方）稳定、合规、支持群发需要 BSP 服务商（如 Twilio/360dialog），有费用
WhatsApp Web 多开 + 自动化免费非官方，有封号风险
n8n WhatsApp 节点集成方便需要官方 API 或第三方桥接

推荐方案：WhatsApp Business API + n8n 集成

WhatsApp Business API (360dialog/Twilio)
    ↓ Webhook
n8n (:5678)
    ├── 解析消息内容
    ├── AI 分类（询价/报价/售后/闲聊）
    ├── 同步聊天记录到 CRM
    ├── 自动回复（常见问题）
    └── 通知业务员（紧急询盘）

CRM 中的 WhatsApp 数据模型扩展：

Contact
  ├── whatsapp_phone: String
  ├── whatsapp_chat_history: Json[]
  │     ├── { from: "customer", message: "...", timestamp: "..." }
  │     ├── { from: "agent", message: "...", timestamp: "..." }
  │     └── ...
  ├── lead_score: Int
  └── ai_classification: String  // "inquiry" | "negotiation" | "after_sales"

模块 4：CRM 系统（trycompai/crm）

职责：客户数据中枢，所有系统最终汇入这里

已有基础：trycompai/crm 是一个 AI-first CRM，有 agent 能力，基于 eve 框架

扩展方向：

CRM 数据来源：
  ├── 独立站询盘表单（WPForms → Webhook → CRM）
  ├── WhatsApp 聊天记录（n8n → CRM API）
  ├── Facebook 互动线索（Postiz → n8n → CRM）
  ├── 手动导入（CSV/Excel）
  └── AI 背调结果（DeepSeek → n8n → CRM）

CRM 需要增加的模块：

模块说明
外贸客户字段扩展公司规模、主营产品、采购量、目标市场、认证需求
询盘来源追踪UTM 参数 + 社媒平台 + 帖文 ID
AI 背调面板调用 DeepSeek 自动查询公司信息、制裁名单、信用评分
报价模块从 CRM 直接生成 PI（形式发票）
邮件/WhatsApp 集成在 CRM 内直接发邮件/WhatsApp

四、n8n 工作流设计（核心胶水）

Workflow 1: 产品目录同步

触发器：Obsidian 文件变更（轮询或 Webhook）
    ↓
读取 .md 文件
    ↓
解析 YAML Frontmatter
    ↓
DeepSeek AI：生成 SEO 标题和描述
    ↓
HTTP Request：WordPress REST API 创建/更新文章
    ↓
记录日志

Workflow 2: 社媒内容自动排期

触发器：每周一 9:00 定时
    ↓
读取 Obsidian /Content/ 目录
    ↓
DeepSeek AI：为每个产品生成 3 条 Facebook 帖文
    ↓
HTTP Request：Postiz API 创建排期帖文
    ↓
通知业务员审核确认

Workflow 3: WhatsApp 聊天同步

触发器：WhatsApp Webhook（新消息）
    ↓
解析消息（发送者/内容/时间）
    ↓
DeepSeek AI：分类消息类型
    ↓
HTTP Request：CRM API 创建/更新联系人
    ↓
if（询盘意向）→ 通知业务员 + 自动回复模板

Workflow 4: 客户背调自动化

触发器：CRM 新联系人（询盘来源）
    ↓
获取联系人信息（公司名/域名）
    ↓
DeepSeek AI + Web Search：背调查询
    ↓
HTTP Request：CRM API 更新联系人背调字段
    ↓
if（风险客户）→ 标记 + 通知

Workflow 5: 独立站询盘同步

触发器：WordPress 表单提交（Webhook）
    ↓
解析表单数据（姓名/公司/产品/数量/邮箱）
    ↓
DeepSeek AI：询盘评分
    ↓
HTTP Request：CRM API 创建联系人 + 询盘记录
    ↓
通知业务员（WhatsApp/邮件）

八、WhatsApp 集成详细方案

推荐：360dialog + n8n

1. 注册 360dialog WhatsApp Business API（月费约 $5-10 起）
2. n8n 安装 WhatsApp 节点
3. 配置 Webhook：
   - 新消息 → n8n → 解析 → CRM
   - 自动回复 → n8n → 360dialog API → WhatsApp
4. 聊天记录格式：
   {
     "contact": "+8613800138000",
     "messages": [
       {"from": "customer", "text": "Hi, I need M10 bolts", "time": "..."},
       {"from": "agent", "text": "What quantity do you need?", "time": "..."},
       ...
     ],
     "crm_contact_id": "xxx",
     "lead_score": 85
   }

备选：WhatsApp Web 自动化（免费但有风险）

使用 wa-automate 或 whatsapp-web.js
    ↓
通过扫码登录 WhatsApp Web
    ↓
监听新消息 → n8n 处理
    ↓
⚠️ 非官方 API，有封号风险

九、客户背调自动化

流程

CRM 新联系人（询盘来源）
    ↓
n8n Trigger（CRM Webhook）
    ↓
DeepSeek AI + Web Search
    ├── Google 搜索公司名 → 获取基本信息
    ├── LinkedIn 搜索 → 决策人信息
    ├── 制裁名单检查（OFAC/EU）→ 风险评估
    └── 海关数据查询（如有）→ 采购记录
    ↓
生成背调报告
    ↓
CRM API 更新联系人字段
    ├── company_info: { ... }
    ├── risk_level: "low" | "medium" | "high"
    ├── credit_score: 0-100
    ├── decision_maker: { name, title, linkedin }
    └── import_history: [ ... ]
