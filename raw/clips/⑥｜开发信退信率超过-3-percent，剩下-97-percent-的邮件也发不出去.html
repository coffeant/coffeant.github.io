开篇：从一份 Excel 到一条能跑通的链路

上一篇结束时，你手上已经有了一张表：几百上千家带联系方式的潜在客户。

现在的问题是： 这张表怎么用，才不会把你的域名和邮箱一起送掉。

下面是完整的四步，顺序不能变。

一、第三步：背调（把不是客户的筛掉）

找到联系方式之后，第一步永远是背调。

三个平台，各看什么（这张表值得存下来）

平台看什么判断的是什么典型字段
LinkedIn员工数、在招岗位、创始人/总监、招聘动向公司规模和实力LinkedIn 主页 / 摘要
Facebook粉丝/Likes、打卡数、评论数与评分、发帖频率客户影响力和口碑Facebook 主页 / 摘要
Instagram粉丝数/帖子数、更新频率、署名出镜的造型师、子账号/分店账号、产品线影响力 + 团队 + 是否连锁Instagram 主页 / 摘要

经验之谈 （以美容沙龙这类客户为例）：

  • LinkedIn 公司主页大多缺失
    ——但员工档案能反推规模；
  • Instagram 通常才是主战场
    。

搜索方法：用域名，别用公司名

很多人背调搜不到，是因为拿公司名去搜。

正确做法： 优先用官网域名 （比公司名精准得多，能过滤同名干扰）。

```

site:linkedin.com/company “域名” 或 “公司名”

site:facebook.com “公司名” (page OR business OR office)

site:instagram.com “公司名” 或 “域名前缀”

```

找到候选后，核对地址/电话/域名确认是这家店，再打开浏览提炼。

⚠️ 让 AI 顺手做三件事（写进指令里，非常值）：

  1. 浏览过程中遇到比原表更准的邮箱/电话/WhatsApp， 更新到原列 ；
  2. 识别占位站点（比如电话是 555-123-4567 、公司名是示例值、地址实际在别的城市）， 写入备注 ；
  3. 多门店连锁， 在摘要里注明门店数和分店账号 。

第 3 点很重要——连锁和个人小店，开发价值完全不同。

可选加分项：海关数据

如果你的目标客户是”跟中国有贸易往来”的，海关数据能补上非常关键的一维： 进口量、采购频次、跟哪些中国供应商在做 。

这需要你有海关数据账号，并且提前在 Chrome 里登录好。

二、第四步：找关键人（KP）

网上找到的信息， 通常都是销售的 。

但你要卖东西，发给销售没用——他是卖东西的，不是买东西的。 你要找的是老板或者采购。

工具：Hunter（以及 Snov、Apollo）

国外这类工具很像国内的企查查——你找到了这家企业，它帮你找关键人。

我选 Hunter 的原因是：它有 API。

这又回到那个万能公式了：

```

API + 说明文档 → 丢给 AI → 它自己用

```

Hunter 免费额度不多（能查几十个），付费档位大概是 30 几美金一个月、2000 个点（现场口径，以官网为准）。

2000 个 KP 的精准开发，一个月你根本用不完。 记住：这不是 EDM，不需要海量。

找出来长什么样

现场演示的结果：

公司 A：2017 年成立，规模 XX，联系方式公开，CEO 姓名、邮箱、LinkedIn 地址， 可信度 99% 。

如果你要开发这个客户，这一条信息基本就够了。

⚠️ 一条硬规矩：找不到 KP 就不要开发

这条我用最重的话说：

找不到关键人，就扔掉。硬发会把你整个开发动作全部污染。

为什么？因为你发给销售的邮件，大概率被无视或被标记；被标记多了，你这个发件域名的信誉就塌了—— 而域名信誉是共用的 。

（后面会讲，这也是为什么一定要用独立的营销域名。）

备选路径：LinkedIn Sales Navigator

日常用的 LinkedIn 每天加人有上限，加多了会被限制。

Sales Navigator 可以理解为”付费版的开发信通道”——有开发客户的额度限制，但有个很妙的机制：

如果客户回复你了，就不消耗额度。

逻辑是：对方愿意回你，说明这不是骚扰。

所以理论上，如果你的开发质量足够高， 你可以用很低的价格开发非常多的客户 。这是”质量换额度”的典型设计。

需要了解或购买 LinkedIn Sales Navigator 的小伙伴，加我微信 jiadingqiang 。

三、第五步：验证邮箱（那条 3% 的红线）

为什么要验证

你找到的那个 CEO 邮箱，有没有可能已经失效了？

太可能了。 总经理跳槽去别家当 CEO，原来公司的邮箱就注销了。而那些工具里搜到的，可能还是那个旧邮箱。

怎么验证

网上一大堆验证工具。我的选择标准只有一个，你已经知道了： 必须有 API 。

因为以前是人干——找到工具、手动输入、看结果；现在是 AI 干，没 API 就没法接。

（PPT 里给的是 BounceBan，同类工具很多，按”有 API”这个标准挑就行。）

⚠️ 红线：退信率

这是整个邮件营销里最硬的一条：

退信率一旦超过 3%，会把剩下 97% 全都污染掉，全都发不出去。

更严格的说法是： 控制在 2% 以下 （PPT 口径）。

所以：

```

无效的邮箱，宁可不发。

```

这不是洁癖，是算术——你为了多发那 3%，损失的是另外 97% 的到达能力。

四、第六步：写开发信（AI 最大的价值在这里）

终于到写信了。

AI 带来的变化：每一封都不一样

这是最关键的一点：

AI 写开发信，可以一秒一封，但 每一封的内容都是不一样的 。

为什么这很重要？因为传统的”群发”是同一段话发给一万个人——平台一秒就能识别。

信该怎么写：从对方的问题出发

不是”我是谁、我卖什么”，而是：

我看了你的网站，你做的是 X，我发现你有这些问题……我能怎么解决。

现场展示的那些邮件，每一封开头都不一样，指出的网站问题也不一样。

这才是”背调”的意义 ——你前面做的所有功课，都是为了这一刻能说出一句跟对方有关的话。

⚠️ 但我必须说一句实话： 回复率的天花板，取决于你的产品痛点够不够痛。

现场有位做了很多年外贸的学员说，他自己写开发信，打开率 30%、回复率 3–4%。他的邮件就三段话，写得很精准。

我的评价是： 3–4% 的回复率，你不用干别的营销了，就靠这个就行了。

所以别迷信”AI 写得更花哨”。AI 的价值是 让每一封都有针对性 ，不是让它替你编痛点。

五、发送：邮箱矩阵，以及为什么不能用一个邮箱猛发

⚠️ 第一条铁律：营销邮箱绝不能是你的工作邮箱

前面讲过绑定工作邮箱让 AI 接管日常邮件——那是另一回事。

开发客户的，一定要换邮箱。

原因：一旦你的主品牌域名被标记为垃圾邮件发送方， 你们全公司所有人的邮件都会进客户的垃圾箱 。连正常的业务往来都发不出去。

核心思路：单个邮箱的发送量必须压到很低

这是邮件营销的基本功，不是什么技巧：

  • 一个邮箱一天硬发 1000 封 → 无论内容多好，送达率都会崩；
  • 把发送量分摊到多个邮箱，每个每天只发几封 → 每个邮箱都处在正常的通信量区间。

因为收件方的信誉评估是 按发送域名和发件地址 来算的。发送行为越接近真人的正常往来，信誉就越稳。

⚠️ 但要说清楚： 这不是”绕过检测”的办法。 低发送量只是保证你的好内容能送到；如果内容本身是无差别的推销，收件人照样会标记你，域名信誉照样会掉。 决定生死的还是内容和名单质量。

成本账（现场口径，以实际为准）

  • 一个域名约 60 元/年 ；
  • 一个域名可以免费注册 3–5 个邮箱 ；
  • 200 个域名 ≈ 12000 元/年 ≈ 1000 个邮箱。

比在平台上投一个月广告便宜多了。 而且域名还能同时用来做站群SEO（第 7 篇），成本进一步分摊。

⚠️ 重要提醒： 同一个域名下如果有一个邮箱被封，同域名其他邮箱都会受影响。 反垃圾是按域名做标识的。所以是”多个域名各注册几个邮箱”，不是”一个域名注册一百个”。

域名注册和邮箱绑定，可以让 AI 辅助

批量域名的注册和邮箱配置是件很枯燥的事，这类重复操作可以交给 AI 去跑。

⚠️ 但注册信息必须真实、合规，该实名的实名—— 域名是你的资产，不是消耗品 。用虚假信息注册的域名，出问题时你什么都拿不回来。

六、邮件营销的九条注意事项（建议打印贴在工位上）

这是 PPT 里我单列的一页，逐条都是踩过的坑：

  1. 每个邮箱每天先从 10–20 封起
    ，稳定后逐步到 30–50 封。 不要一上来猛发。

（新邮箱需要”养”，这是行业常识。）

  1. 用多个独立的发送域名/子域名
    ，不要拿主品牌官网域名硬发冷邮件。
  2. 每个域名配 2–3 个邮箱
    更稳，别一个域名挂几十个。
  3. 必须配置 SPF / DKIM / DMARC。

这三项是邮件安全与送达率的”三大黄金协议”，被称为 域名的”信誉卡” 。不配，你发什么都白搭。

  1. 名单先验证，退信率最好控制在 2% 以下。
  2. 邮件内容要短、要具体、要像真人写的。

不要大图、不要群发模板感、不要很多链接。

  1. 最好关闭或谨慎使用打开追踪/点击追踪。

冷邮件里的追踪链接，非常伤送达率。

  1. 每封都要有清晰的退订方式。
  2. ⚠️ 合规红线 ：美国 CAN-SPAM 要求商业邮件不得误导身份与标题，且 必须允许退订 ；FTC 有明确指南。这不是建议，是法律要求。

开发客户不是”发得越多越好”。 你每天其实发不了太多 ——因为你找不到那么多合格客户。

真实的节奏是： 经过画像、背调、找 KP、验邮箱之后，每天每个邮箱就发三五封，送达率会非常高。

七、顺带说一个高价值场景：盘活老客户库

很多公司真正的问题不是没客户，是：

库里躺着十万个客户，全是行业内的，就是没人理。

这套东西接到你的公海库上，反而更简单—— 背调都省了 ，那都是你以前开发过的客户，有联系方式、有客户情况。

做法：

  1. 从 CRM 里导出成 Excel / CSV（尽量全，别只有一个邮箱——历史跟进记录、来源渠道都导出来）；
  2. 丢给 AI，让它一行一行读、一行一行生成；
  3. 自动发。

⚠️ 关于”自动跟进长期未联系客户”：这个场景可以实现，而且不难——用 Agent 的定时任务，每周导出”超过 N 天没联系”的客户，接上邮箱自动发一轮。

但我要给个提醒： 一旦进入销售层面（分阶段、分话术、判断意向），事情就会变得很复杂 ，因为它需要每个企业自己定义规则。营销端的容错率高，发错了不是你的客户，无所谓；销售端的容错率低。

（这个边界在第 10 篇展开。）

本篇清单

  • 背调三平台分工： LinkedIn 看规模 / Facebook 看口碑 / Instagram 看影响力与连锁
  • 背调搜索 用官网域名 ，别用公司名
  • 找 KP： Hunter / Snov / Apollo ，选有 API 的
  • ⚠️ 找不到 KP 就扔掉 ，硬发会污染整个开发动作
  • ⚠️ 退信率红线 3%（建议控制在 2% 以下） ——超了会污染全部
  • 开发信从 对方的问题 出发，不是从”我是谁”出发
  • ⚠️ 营销邮箱绝不用主品牌域名和工作邮箱
  • 邮箱矩阵：多域名 × 每域名 3–5 个邮箱 × 每箱每天三五封
  • 必须配 SPF / DKIM / DMARC
  • 每天 10–20 封起步，逐步放量；关闭追踪；必须可退订；遵守 CAN-SPAM
  • 老客户库：导出 CSV → AI 逐行读 → 自动发

从下一篇开始，进入”客户找你”这条腿。

我会先演示一个让现场笑出声的例子： 用一句话让 AI 生成了一个八字排盘网站 （对，就是那种输入生日出命盘的网站），它当场就在浏览器里打开了。
